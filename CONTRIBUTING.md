# Contributing

This document shows you how to make a pull request.

## Downloading & Editing

1. Download the code via zip file.
2. Edit some typos or add more details to the docs, change errors in some schematics, etc

## Making a pull request
1. Edit files to your desire.
2. Make a fork.
3. Make a pull request.
4. I will check and review the pull request soon.
