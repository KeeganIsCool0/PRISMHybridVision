# Security Policy

## Supported Versions

The latest version of this repo is being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.2    | :white_check_mark: |
| v1.0    | :x:                |
| v1.1    | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Please report a security venerability at the issues and pull requests tab on git.
