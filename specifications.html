PRISM Specifications

Audio Performance

  • 24-bit/192kHz ADC/DAC
  • 120 dB dynamic range
  • 0.001% THD+N
  • 20Hz-20kHz frequency response (±0.1dB)

Connectivity

  • 16 XLR/TRS combo inputs
  • 8 balanced line outputs
  • 2 headphone outputs (6.3mm & 3.5mm)
  • MIDI I/O (5-pin DIN)
  • USB 3.0, Thunderbolt 3, Ethernet
  • Word Clock in/out

Processing

  • Quad-core DSP engine
  • 64-bit floating point processing
  • Zero-latency monitoring
  • Built-in effects suite
  • Standalone operation mode

Physical

  • 19" rack mountable (3U)
  • Aluminum chassis
  • Weight: 8.5 lbs (3.9 kg)
  • Power: 100-240V AC, 50W
  • Operating temp: 0-40°C (32-104°F)
