Technology

Engineering the PRISM Architecture

PRISM Hybrid Vision combines modular analog audio processing with digital control, recall, automation, and modern production workflows.

The system is designed around a modular architecture so individual sections can be developed, replaced, upgraded, and tested without requiring the entire console to be redesigned.

Hybrid Signal Path

PRISM combines analog audio processing with digital control and integration. This allows the signal path to retain analog processing characteristics while providing the flexibility expected from a modern digital production system.

Modular Architecture

The console is designed around replaceable modules. Individual processing sections can be developed, serviced, upgraded, or replaced without replacing the entire console.

Digital Recall

Digital control allows console settings to be recalled and automated while maintaining dedicated analog processing in the audio path.

DAW Integration

PRISM is designed to work alongside modern digital audio workstations, allowing the console to become part of a larger production and automation workflow.

Immersive Audio

The architecture is designed with immersive production in mind, including support for large-format routing and modern surround workflows.

Expandable System

PRISM is designed to grow with the needs of its users. Modular processing and system expansion allow future capabilities to be incorporated into the platform.

System Architecture

PRISM separates the audio signal path from the control architecture while allowing the two systems to work together as one console.

uAMX Modular Technology

PRISM uses uAMX as part of its modular system architecture. The goal is to make the console's processing architecture adaptable while reducing the need to replace an entire system when individual functionality needs to change.

Preamp

Analog microphone and line-level input processing.

EQ

Modular equalization and tonal shaping.

Compressor

Dynamic processing integrated into the channel path.

Mix Bus

Routing and summing architecture for the console.

Control

Digital control, recall, and automation systems.

Digital Control

Digital control is used to provide modern workflow features without requiring the entire audio path to become digital. This allows PRISM to combine hands-on analog processing with recallable and automated control.

Recall

Console settings can be digitally stored and recalled as part of a session.

Automation

Digital control architecture allows parameters to be incorporated into automated workflows.

Microcontrollers

Distributed control electronics can manage groups of channels and their associated hardware.

DAW Communication

PRISM is designed to integrate its control system with modern digital production environments.
