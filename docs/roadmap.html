Roadmap

Phase 1: Architecture

  • ✔ Define console architecture: Define console architecture by brainstorming
  • ✔ Define Modular Channel Strip: Define overall channel strip
  • ✔ Establish uAMX Interface: Find how uAMX will be implemented
  • ✔ Finalize System Block Diagram: Build system block diagram
  • ✔ Finalize Power Architecture: Finalize power architecture
  • ✔ Finalize DAW/automation architecture: Finalize DAW/automation architecture

Phase 2: Core Design

  • ✔ Complete Channel Strip Schematic: Build and test schematic in KiCAD
  • ✔ Complete mix-Bus Schematic: Complete and test mix bus schematic
  • ✔ Complete Module Schematic: Complete schematics for each module
  • ✔ Finalize uAMX pin assignments: Assign pins to uAMX
  • ✔ Finalize PCB Layout: Complete PCB layout for all modules

  • ✔ Executive Summary: Execute summary of the project

  • ☐ Sponsorship Secured: Secure sponsorships for the project

Phase 4: Prototyping

  • ☐ Order Components: Order all necessary components
  • ☐ Build Prototype Channel: Build the initial prototype channel
  • ☐ Integrate modular processing: Integrate modular processing into the prototype
  • ☐ Integrate microcontroller: Integrate the microcontroller into the prototype
  • ☐ Test complete signal path: Test the complete signal path for functionality and performance
  • ☐ Measure Nose, Frequencies, Distortion, and Crosstalk: Measure these parameters for the prototype
  • ☐ Document Testing Results: Document the results of all testing activities
  • ☐ Revise and Optimize: Revise and optimize the prototype based on testing results

  • ☐ Build control computer: Build the control computer for console operation
  • ☐ Implement Module Identification: Implement module identification for the console

  • ☐ Integrate multiple modules: Finalize the designs for all modules
  • ☐ Build 8-channel prototype: Build the 8-channel prototype for the console
  • ☐ Build software and firmware: Build the software and firmware for the console
  • ☐ Complete System testing: Complete system testing for the prototype
  • ☐ Document System Testing Results: Document the results of all system testing activities

Phase 7: Final Product

  • ☐ Finalize Designs: Finalize all designs for the console
  • ☐ Build Final Product: Build the final product for the console
