Getting Started

Welcome to the PRISM Recording Console documentation. This guide will help you set up and start using your PRISM console.

  1. Unpack the console and place it in your desired location.
  2. Connect power and audio interfaces.
  3. Install the PRISM Control Software from our website.
  4. Follow the on-screen setup wizard.

FAQ

What operating systems are supported?

PRISM Control Software is available for Windows 10+, macOS 10.15+, and Ubuntu Linux 20.04+.

Can I use PRISM without a computer?

Yes! PRISM can operate in standalone mode using its built-in touchscreen interface.

What warranty does PRISM come with?

PRISM includes a 3-year limited warranty covering parts and labor.
